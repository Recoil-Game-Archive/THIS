Music for THIS

Put .ogg files in this folder (or in one folder below it) and the in-game
music player picks them up: it plays them in a shuffled order and shows the
track name in the game menu (Esc), with previous, pause and next.

The track name shown is the file name without ".ogg"; underscores become
spaces and a leading track number is dropped, so "03_Deep_Field.ogg" shows
as "Deep Field".

Players can add their own music the same way: a "music" folder next to the
"games" and "maps" folders of their Recoil data directory is read as well.
